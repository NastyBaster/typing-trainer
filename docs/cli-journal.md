# Журнал CLI та перевірок

Цей файл зберігає коротку історію навчальних дій. Він не замінює `git log`: тут
важливі причини рішень, результати ручних перевірок і проблеми, з якими зіткнувся
учень.

## Як вести журнал

Після завершення робочої сесії додай запис за шаблоном:

```markdown
## YYYY-MM-DD — step-XX-name

- Мета сесії:
- Виконані команди:
- Змінені файли:
- Перевірки в браузері:
- Помилки та як їх виправлено:
- Що залишилося зробити:
```

Не записуй паролі, токени, приватні ключі або інші секрети. Довгий вивід команд
переказуй стисло, залишаючи тільки те, що допоможе відтворити рішення.
