# Контекст проєкту

## Продукт

Навчальний проєкт «Тренажер сліпого набору тексту» — браузерний застосунок, у
якому користувач набирає еталонний текст і поступово отримує підсвічування
символів, таймер, WPM, Accuracy, вибір тексту та складності.

## Навчальна мета

Проєкт потрібен не лише як готовий продукт. Його головна цінність — послідовне
вивчення HTML, CSS, DOM, браузерних подій і керування станом на чистому
JavaScript. Учень набирає код самостійно та може пояснити кожен суттєвий рядок.

## Обмеження

- Лише HTML5, CSS і JavaScript ES6+.
- Без сторонніх бібліотек, фреймворків, збирачів і тестових утиліт.
- Без копіювання повної готової реалізації від ментора.
- Кожний модуль зберігається в окремій Git-гілці та після перевірки вливається в
  `main`.
- Перевірка виконується в браузері, DevTools і за допомогою простих Git-команд.

## Навчальний цикл

1. Прочитати README поточної гілки.
2. Створити гілку за наведеною командою.
3. Виконувати по одному пункту чек-листа.
4. Після кожного логічного блоку перевіряти результат.
5. Якщо щось не працює — описати очікуваний і фактичний результат, а також
   повідомлення Console.
6. Виконати всі критерії готовності.
7. Відповісти на питання для самоперевірки.
8. Лише після рев'ю зробити commit і merge.

## Поточний стан

- Виконана і перевірена реалізація поточного кроку: `step-01-base-html`.
- Статус: реалізовано верстку сторінки.
- Наступна дія учня: — commit, PR і merge.
- Файли застосунку `index.html`, `style.css` та `app.js` вже створені.

## Архітектурні рішення, прийняті наперед

- `index.html` буде єдиною вхідною сторінкою.
- `style.css` міститиме всі стилі до моменту, коли поділ стане навчально
  виправданим.
- `app.js` підключатиметься як зовнішній скрипт.
- На етапі введення використовуватимемо подію `input`, а не застарілу
  `keypress`.
- WPM рахуватиметься за стандартною навчальною одиницею: 5 правильних символів
  дорівнюють одному слову.
